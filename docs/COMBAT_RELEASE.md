# Combat build v0.2.0

2026-11-04。ユーザー依頼のCPU戦・BR・弾道・的の更新・3視点・人型モデルを実装。

## 動作

- CPU戦：プレイヤー対3CPU。BR：8人の個人戦。CPU同士も戦う。
- 有限弾薬、再装填、遮蔽物、体・頭部の射撃判定、HP/シールド、撃破、勝敗・順位。
- BRは添付定数の10分の安全地帯、圏外ダメージ、ミニマップ。物資取得・2秒の回復。
- CPUの視線確認、接近・巡回、再装填、弾薬探索、物資取得・回復。
- 銃口から弾の先端とトレーサーを移動させる。ヒットスキャンによる命中判定とは分離。
- 練習の的は1命中で倒れ、再命中を受け付けず、約1秒後に別の的が出現。5撃破ごとに同時出現数を増やし、最大12体。
- Vで一人称→二人称（プレイヤー正面）→三人称。停止画面でも選択。三人称の照準は射線を投影し、追従カメラは壁を避ける。
- プレイヤー・CPUのローポリ人型モデル、脚の動き、しゃがみ・倒れるCPU。
- 対戦結果を別キーに保存。試合IDで重複防止。既存の設定保存データを移行・破壊しない。

## 検証

- TypeScriptの型検査と本番ビルドに成功。
- 単体テスト31件成功：既存処理14件、対戦・的16件、戦績保存1件。
- `tests/browser.py`：本番サブパスで操作・設定保存・一時停止/再開・単発DMR・破棄・既存データ保護・WebGL非対応案内・320〜1440pxの表示に成功。新しい的への変更後、5発以上の実発射と1命中を確認。
- `tests/combat_browser.py`：本番サブパスで3モード、新しい的、3視点、人型表示、実際の射撃によるCPU撃破、BRのミニマップ・終了・順位・保存・再戦・戦績表示・レスポンシブ表示に成功。状態の注入や勝敗の偽装はしない。未処理のJavaScriptエラーなし。
- 実ブラウザーはChromium＋ソフトウェアWebGL。描画速度に依存する固定の待ち時間ではなく、発射数・撃破等の実際の状態を待つ。
- 添付の全体受け入れマトリクスは原文を保持し、未確認項目を合格に変更しない。

## 制限

二人称は「対戦相手の目から見る」モードではなく、正面からプレイヤーを見る観察カメラ。
オンライン対戦・途中試合の保存/再開・難易度選択・本格的なナビメッシュは未対応。
実機GPUの性能・Safari/Firefox・効果音の聞こえ方は未検証。スマートフォンでの対戦操作は提供しない。
