# DROPZONE — UI/UX 正本（ゲーム画面と操作フロー）

## 1. 画面構成

### Home（初回起動）
- PC：左サイドバー幅244px（ロゴ、HOME/PLAY/TRAINING/STATS/SETTINGS/HELP）。中央：大きな抽象SFアリーナのヒーロー領域、「バトル開始」（主要CTA）、「射撃練習」（副CTA）、説明。右：自身のBR戦績「勝利、試合数、撃破、平均順位」。戦績なしはゼロ・空状態を表示。モック数値禁止。
- Home右上：サウンドON/OFFと設定。中断セッションがあるときだけ「続きから」が主要CTAの近くに表示。
- 構造はレスポンシブ：1200px以上はsidebar + content + statRail、768～1199pxはsidebarアイコン化と統計カード下段、768px未満は1カラム・説明/戦績のみ、プレイボタンは無効で理由文。

### ModeSelect
- 目的：「ソロ BR」固定＋難易度 easy/normal/hardの3カード。難易度はCPUの反応速度/照準誤差のみを変えると記載。
- 「開始」を押すと loading→ready。ロード中はスピナー＋「マップを準備中」。「クリックして開始」ボタンはready状態のみ出す。

### Battle / Training
- 画面全体をCanvasにする。上から重ねるHUDはReact DOM、Canvasにカーソルが重なっても必要なテキストは読みやすい。FPS中はマウスがロックされ、ポーズ以外HUDをクリックできない設計。
- 左上：経過時間、キル数、戦闘ログ最大5件／5秒表示。
- 上中央：方位（N/E/S/W）と警告バー（区域縮小、場外）。右上：プレイヤー含む残存数、ミニマップ。中央：照準レティクル（ADS時縮小）、被弾インジケータ。
- 左下：HPバー・Shieldバー・回復キット数、`Q 回復`ヒント。右下：武器名、`マガジン / 予備弾`、`R リロード`、スロット `1 / 2`。
- 埋め込みヒント：物資との距離<=2.2mのみ`E 入手 [物資名]`、可否メッセージ。後ろのシールドに暗い半透明プレートを使い文字のコントラストを担保。
- 効果音・被弾方向・発射光・ヒットマーカーは通常ON、設定に応じて無効化。敵HPバーは **直接視認できる敵のみ** に表示。

### Pause
- 半透明暗色オーバーレイでメニューを表示。ボタン「試合を再開」「設定」「試合を破棄（確認ダイアログ）」、中断時の保存状態表示。
- 再開クリック→Pointer Lock申請→成功時だけplaying。未取得時はメニュー維持。破棄で確認なし即中止は不可。

### Result
- 勝敗タイトル。個人成績（順位、撃破、命中率、ダメージ、生存時間）と「再戦」「ホーム」。試合結果は保存成否を明示。スコアが実際に確定するまでは空の数値を仮表示しない。

### Stats
- 端末内ランキングは **個人のベスト記録**。総試合/勝敗/勝率/総撃破/最大ダメージと、直近100試合の表。順位は1（優秀）～8。引分は順位の`—`。

### Settings / Help
- Setting input: マウス感度 0.1〜3.0（step0.1、default1.0）、全体音量0〜1（step0.1、default0.7）、SFX ON、描画 low/medium/high default medium、UI倍率0.8〜1.4 default1.0、FPS表示OFF、動作軽減（OSのprefers-reduced-motion default反映）、色の補助ON/OFF。
- 変更は即時反映し保存（スライダー操作中は150ms debounce）、元に戻すは確認付き。音声が使えない時も設定保存はできる。
- Helpはキーボード操作一覧、エイム/スプリント/回復、ゾーンの意味、端末内保存制約、初版にオンライン対戦がないこと、WebGLとマウスが必要なことを記載。

## 2. 見た目と情報設計

- `design/tokens.css`の色を正本とする。ダークネイビー #080F1D、メニュー #101C2F、カード #14223A、文字 #EDF4FF、muted #A9BDD8。アクセント：橙 #F28B35（危険・敵・アクション）、青 #47AAFF（シールド・現在の選択）、緑 #49CE9C（成功）、赤 #F16464（HP低下）。
- ヘッダーサイズ16/24px、本文14〜16px、密集HUDは12px未満禁止。カード角14px。ボタン44px以上、操作焦点2px以上。
- シールドの青・体力の緑・危険の橙に文字値を併記。色だけで情報を伝えない。
- ミニマップ寸法PC 180×180px、狭い幅では140px、スクリーンリーダーには位置の要約テキストを代替提供。
- ライトモードは初版に搭載しない。背景もゲームもダーク系で統一する（要望がない別のテーマは追加しない）。
- アニメーションの優先順位：命中したことのフィードバック ＞ ボタンの変化 ＞ 装飾。低負荷設定でParticle/影を減らすが射撃・遮蔽は同一結果。

## 3. シーンの遷移表

| 現在画面 | 操作 | 次の画面 | 処理 |
|---|---|---|---|
| home | バトル開始 | mode-select | 難易度選択 |
| home | 射撃練習 | training | 練習場生成、ロック待機 |
| home | 続きから | pause | 有効snapshotを検証、pausedで復帰 |
| mode-select | 開始 | match | session作成→loading→ready→ユーザークリックでplaying |
| match | Esc / blur | pause | 停止/保存/ロック解除 |
| pause | 再開 | match | Pointer Lock成功時のみ更新再開 |
| pause | 試合破棄→確認 | home | 統計加算なし、currentMatch削除 |
| match | 勝利/敗北/時間終了 | result | Stats重複計上防止、snapshot削除、ロック解除 |
| result | 再戦 | mode-select | 同じ難易度初期値、新しいシード |
| result | ホーム | home | 画面戻り |
| home | 戦績 / 設定 / ヘルプ | stats / settings / help | HTML UIだけ表示 |

## 4. 失敗時のデザイン

- WebGL不可：ページ全体が真っ黒にならないよう、通常React UIで具体的なメッセージとヘルプ導線。
- 保存失敗：レッドトースト＋ポーズ画面の固定注意。ゲーム続行可。
- ポインターロック拒否：ロード中に戻さず「クリックして再試行」ボタン。Escでも意図せぬ再開を起こさない。
- ネットワークなし：アセットは同梱でゲームが動く。CDNへの通信が前提のフォントや画像は使用しない。
- FPSが低い：UIにFPS数値（設定ON時）とlow設定への切替案内。性能限界を隠さない。
